# Contribuir

Consulte o README para criar conteúdos e traduções. Use português europeu e mantenha a correspondência PT/EN através de `translationKey`.

Não publique dados não confirmados, imagens sem autorização ou entradas DEMO como notícias reais. Trabalhe numa branch e reveja a pré-visualização. Antes de propor alterações, execute `npm run format`, `npm test` e `npm run format:check`.

Faça alterações ao tema através de overrides na raiz. Preserve os avisos de licença e os créditos das imagens. Não inclua dados pessoais sem autorização.
